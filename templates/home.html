Sobre este projeto acadêmico

Este sistema foi desenvolvido como projeto prático do curso técnico em Desenvolvimento de Sistemas. O foco desta versão prioritária é a integridade das operações de CRUD do módulo de colaboradores, a validação no servidor com Django ORM e a persistência de dados em banco SQLite.
